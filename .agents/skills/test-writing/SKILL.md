# Test routing (monorepo)

Read `project-base/.agents/skills/test-writing/SKILL.md`, then apply
`.agents/skills/monorepo-vs-project/SKILL.md`.

When routing to `backend-tests` or `storefront-tests`, read the matching monorepo
entrypoint under `.agents/skills/` so its package-specific additions are applied.
For Cypress, always read `.agents/skills/cypress-tests/SKILL.md`.
