# PHPStorm Settings

If you are using PHPStorm, we have prepared code scheme for you to work easily with Commerce Cloud including Javascript Storefront.

## Importing new scheme in PHPStorm

*Note: This guide will import new scheme in your PHPStorm, your previous schemes and other PHPStorm settings will not be changed.*

- To configure your IDE, select `PhpStorm -> Preferences` for macOS or `File -> Settings` for Windows and Linux.
- From menu select `Editor -> Code Style`
- Right of `Scheme` select box is cogwheel, click it and select `Import Scheme...`
- Import file `storefront/config/phpstorm/phpstorm.xml`
- Now you will see new scheme in Scheme select box
- Make sure that you have selected this scheme for PHP, Javascript and Typescript

*Note: In some cases it is necessary to invalidate cache (`File -> Invalidate Caches ...`) and restart PHPStorm for changes to take effect.*
