#Image sitemap
- generated for each domain
- generated only for main image of visible product and blog article image
- generated by cron

If you change the type / size of the image used in the template, you also need to change the type / size in the image sitemap (ImageSitemapFacade).

For more see: [FWCC-84](https://shopsys.atlassian.net/browse/FWCC-84) or [Google Image Sitemaps docs](https://developers.google.com/search/docs/advanced/sitemaps/image-sitemaps)
