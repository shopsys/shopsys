# Installation Using Kubernetes on Production Server

For the production installation and deployment of Shopsys Platform, we recommend using Kubernetes.
We maintain [shopsys/deployment](https://github.com/shopsys/deployment) repository that contains the latest deployment scripts and instructions for Shopsys Platform.
The setup with Kubernetes and Gitlab CI is described in detail in the [README](https://github.com/shopsys/deployment/blob/main/README.md) file of the repository.
