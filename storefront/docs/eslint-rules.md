### sort-imports

-   This rule enforces certain order of imports on the top of the file
-   Generally all imports have to be sorted alphabetically
-   Letter cases are ignored
-   Then the order is:
    -   **None** - import from 'example'
    -   **All** - import \* from 'example'
    -   **Multiple** - import Foo, Bar from 'example'
    -   **Single** - import Foo from 'example'
