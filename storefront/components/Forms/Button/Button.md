### Examples

```jsx padded
<Button type="button" name="button1">Default</Button>
<Button type="button" variant="primary" name="button2">Primary</Button>
<Button type="button" variant="secondary" name="button3">Secondary</Button>
```

### Sizes

```jsx padded
<Button type="button" name="button4">Default</Button>
<Button type="button" size="small" name="button5">Small</Button>
```

### Combinations of variants and sizes

```jsx padded
<Button type="button" size="small" variant="secondary" name="button6">Default</Button>
<Button type="button" size="small" variant="primary" name="button7">Small</Button>
```
