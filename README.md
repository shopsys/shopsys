# SSFWCC

## Installation

To install project SSFWCC locally, run install script `./scripts/install.sh` and follow installing steps.
After installation, you should be able to access backend as well as frontend.

* Storefront is ready under http://127.0.0.1:8000
* Administration is ready under http://127.0.0.1:8000/admin, you can log in using username `admin` and password `admin123`
