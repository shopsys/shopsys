# Gift voucher PDF fonts

These fonts are embedded into the gift voucher PDF generated by
`Shopsys\FrameworkBundle\Model\GiftVoucher\GiftVoucherPdfDocument` (FPDF).

## Bundled fonts

- **DejaVu Sans** (`DejaVuSans.ttf`)
- **DejaVu Sans Bold** (`DejaVuSans-Bold.ttf`)

## Generated FPDF definitions

`*.json` and `*.z` are the FPDF font definition and the compressed, subsetted
font program. They are generated from the `*.ttf` sources with the `CP1250`
(Central European) encoding so Czech and Slovak diacritics render correctly.

To regenerate them after replacing a `*.ttf`, run inside this directory:

```sh
php vendor/setasign/fpdf/makefont/makefont.php DejaVuSans.ttf cp1250 true true
php vendor/setasign/fpdf/makefont/makefont.php DejaVuSans-Bold.ttf cp1250 true true
```
