#### Cron modules are covered by a smoke test ([#5009](https://github.com/shopsys/shopsys/pull/5009))

- `Tests\App\Functional\Component\Cron\CronSmokeTest` runs all registered cron modules without a selected domain and a current locale, the same way they run in a console process
    - when your own cron module calls an external service, replace the service in the test environment (`Tests\FrontendApiBundle\Functional\Payment\GoPay\GoPayClientFactory` and the category feed parameters in `app/config/services_test.yaml` are examples)
    - when the service cannot be replaced, add the cron module with a reason to `CronSmokeTest::getExcludedCronModules()`
- `Tests\FrameworkBundle\Test\TestTranslatableListener::getCurrentLocale()` now returns `?string`, update your extension of the class, if you have one
- see #project-base-diff to update your project
