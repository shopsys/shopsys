#### Flag categories in Frontend API are no longer limited to 10 ([#4946](https://github.com/shopsys/shopsys/pull/4946))

- `FilterQuery::getAggregationQueryForProductCountInCategories()` now limits the categories aggregation by `MAXIMUM_REASONABLE_AGGREGATION_BUCKET_COUNT` instead of the default Elasticsearch size of 10 buckets
