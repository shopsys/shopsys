#### Add cooldown policy for newly released dependencies ([#5010](https://github.com/shopsys/shopsys/pull/5010))

- pnpm now withholds newly published package versions for 7 days, which limits the exposure to a compromised release
- copy `pnpm-workspace.yaml` with the `minimumReleaseAge` setting into your storefront (see #project-base-diff), it needs pnpm 10.16 or newer
- `pnpm install --frozen-lockfile` is not affected, the policy applies when the lockfile is resolved (`pnpm add`, `pnpm update`)
- to install a version that is still in cooldown (e.g., a security fix you have reviewed), run the command with `--config.minimumReleaseAge=0`
- see #project-base-diff to update your project
