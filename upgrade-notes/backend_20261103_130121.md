#### Fixed security issues of uploaded files, GoPay notification and registration ([#5013](https://github.com/shopsys/shopsys/pull/5013))

- `Shopsys\FrameworkBundle\Component\UploadedFile\UploadedFileFacade::isUploadedFileViewableInBrowser()` and the `VIEWABLE_EXTENSIONS` constant were moved to `Shopsys\FrameworkBundle\Component\AbstractUploadedFile\AbstractUploadedFileFacade`, the method now accepts `Shopsys\FrameworkBundle\Component\AbstractUploadedFile\AbstractUploadedFile`
    - if you override the method, change the parameter type from `Shopsys\FrameworkBundle\Component\UploadedFile\UploadedFile` to `Shopsys\FrameworkBundle\Component\AbstractUploadedFile\AbstractUploadedFile`
- `Shopsys\FrameworkBundle\Controller\Front\PaymentStatusNotifyController::notifyAction()` now requires a valid order UUID in the `orderIdentifier` query parameter and the GoPay payment id in the `id` query parameter matching one of the order's `Shopsys\FrameworkBundle\Model\Payment\Transaction\PaymentTransaction::$externalPaymentIdentifier`, otherwise it responds with 404
    - if you call the `front_order_payment_status_notify` route from your own payment gateway integration, pass the external payment identifier as the `id` parameter
- see #project-base-diff to update your project
