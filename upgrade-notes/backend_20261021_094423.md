#### Escape dynamic values in administration raw outputs ([#XXXX](https://github.com/shopsys/shopsys/pull/XXXX))

- `Shopsys\FrameworkBundle\Component\ConfirmDelete\ConfirmDeleteResponseFactory::createDeleteResponse()` renders the message as raw HTML, so pass dynamic values (entity names, labels, e-mails) in the new `$messageParameters` argument, where they are escaped, instead of `t()` parameters
    ```diff
    - $message = t('Do you really want to remove rate "%name%" permanently? It is not used anywhere.', ['%name%' => $vat->getName()]);
    - return $this->confirmDeleteResponseFactory->createDeleteResponse($message, 'admin_vat_delete', $id);
    + $message = t('Do you really want to remove rate "%name%" permanently? It is not used anywhere.');
    + return $this->confirmDeleteResponseFactory->createDeleteResponse($message, 'admin_vat_delete', $id, ['%name%' => $vat->getName()]);
    ```
    - pass a list of values shown one per line (e.g. customer e-mails) as an array of strings instead of joining them yourself, its items are escaped and joined with `<br>`
- `Shopsys\FrameworkBundle\Component\FlashMessage\FlashMessageService::addSuccessFlash()`, `addErrorFlash()`, `addInfoFlash()`, and `addWarningFlash()` (and the same methods of `Shopsys\FrameworkBundle\Component\FlashMessage\FlashMessageTrait`) now escape the message
    - replace the calls whose message contains HTML with `addSuccessFlashTwig()`, `addErrorFlashTwig()`, `addInfoFlashTwig()`, or the new `addWarningFlashTwig()` and pass the dynamic values as template parameters; never put values into the template string, they would be compiled as Twig code
    ```diff
    - $this->addSuccessFlashTwig(t('Holiday / internal day <strong>{{ name }}</strong> deleted', ['{{ name }}' => $closedDayName]));
    + $this->addSuccessFlashTwig(t('Holiday / internal day <strong>{{ name }}</strong> deleted'), ['name' => $closedDayName]);
    ```
    - the `*FlashTwig()` methods no longer call the `add*Flash()` methods, so if you override `add*Flash()` to customize all flash messages, override `addFlashMessage()` instead
- if you override methods of `Shopsys\FrameworkBundle\Twig\RequiredSettingExtension` that put warehouse, parameter, or domain names into the warnings, escape the names with the new `escape()` method
- if you override `@ShopsysAdministration/content/notificationBar/listGrid.html.twig`, replace `{{ value|raw }}` with `{{ value|sanitize_html('shopsys.ckeditor_preview') }}` in the `grid_value_cell_id_text` block
- see #project-base-diff to update your project
