#### Reduce SQL queries of frequent Frontend API operations ([#5060](https://github.com/shopsys/shopsys/pull/5060))

- `Shopsys\FrameworkBundle\DependencyInjection\ServicesResetter` now gets its `$resettableServices` argument from `Shopsys\FrameworkBundle\DependencyInjection\Compiler\RegisterResettableServicesCompilerPass` and resets only the services that were already initialized
    - if you set this argument in your own definition of the service, remove it, the compiler pass overwrites it
- if you added the conflict with `scheb/2fa-bundle` version `7.15.0` to your `composer.json` to be able to install the project, you can remove it
- constructor of `Shopsys\FrameworkBundle\Model\Module\ModuleFacade` changed its interface:
    ```diff
        public function __construct(
            protected readonly EntityManagerInterface $em,
            protected readonly EnabledModuleRepository $enabledModuleRepository,
            protected readonly EnabledModuleFactory $enabledModuleFactory,
    +       protected readonly InMemoryCache $inMemoryCache,
        ) {
    ```
- `Shopsys\FrameworkBundle\Component\Cache\InMemoryCache` now keeps the values in the `$valuesByNamespace` array instead of nested cache adapters
    - property `$namespacesCache` and method `getNamespaceCache()` were removed, update your class if it extends `InMemoryCache` and uses them
    - `getOrSaveValue()` no longer calls `hasItem()`, `getItem()` and `save()`, so if you override these methods, override `getOrSaveValue()` as well
- see #project-base-diff to update your project
