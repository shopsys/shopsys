#### Add cooldown policy for newly released dependencies ([#5010](https://github.com/shopsys/shopsys/pull/5010))

- Composer 2.11+ can withhold newly published package versions for a configurable period, which limits the exposure to a compromised release
- add the `policy` section into `config` in your `composer.json` (see #project-base-diff) and run `composer update --lock` to refresh the lock file hash
- `composer install` is not affected, `composer update` and `composer require` now skip versions released less than 7 days ago
- to install a version that is still in cooldown (e.g., a security fix you have reviewed), run `composer update --no-cooldown vendor/package`
- see #project-base-diff to update your project
