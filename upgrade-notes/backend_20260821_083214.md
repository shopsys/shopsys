#### Mass generated promo code batch now downloads as a CSV file ([#4790](https://github.com/shopsys/shopsys/pull/4790))

- methods `findByMassBatchId()` in `Shopsys\FrameworkBundle\Model\Order\PromoCode\PromoCodeFacade` and `Shopsys\FrameworkBundle\Model\Order\PromoCode\PromoCodeRepository` now declare `array` return type instead of `?array` — update the return type in your overrides of these methods and remove any `null` checks on their result
- `Shopsys\FrameworkBundle\Controller\Admin\PromoCodeController::downloadMassGenerateBatchAction()` now sends the batch as `promoCodesBatch-{batchId}.csv` with `text/csv` content type, returns 404 for a non-existent or non-numeric `batchId`, and the protected `generateCsvFromPromoCodeFromBatchId()` method throws `Symfony\Component\HttpKernel\Exception\NotFoundHttpException` for an empty batch — update your overrides of this action or method and any tests asserting the old extensionless download accordingly
