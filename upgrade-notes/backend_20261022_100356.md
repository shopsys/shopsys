#### Preserve removed gifts and unify purchase and order presentation ([#4966](https://github.com/shopsys/shopsys/pull/4966))

- if you override `Shopsys\FrameworkBundle\Model\Product\GiftPlan\GiftCartFacade::refreshProductGiftsInCart()`, `Shopsys\FrameworkBundle\Model\Product\GiftPlan\GiftCartFacade::refreshProductGiftCartItemsAndGetInvalidItems()`, `Shopsys\FrameworkBundle\Model\Cart\CartFacade::removeItemFromExistingCartByUuid()` or `Shopsys\FrontendApiBundle\Model\Cart\MergeCartFacade::mergeCarts()`, update them accordingly: a gift removed by the customer is marked by `Cart::markProductGiftRemoved()`, must not be added back while `Cart::isProductGiftRemoved()` returns true, and is carried over during cart merging by `Cart::mergeRemovedProductGifts()`
- replace calls to the `orderItemRows` macro from `@ShopsysFramework/Mail/Order/products.html.twig` with `orderItemRow`; it now returns a complete presentation table, so update surrounding table markup accordingly
- `Shopsys\FrameworkBundle\Migrations\Version20261021120000` updates the `order_status_1`–`order_status_4`, `watchdog_mail`, `product_inquiry_customer` and `product_inquiry_admin` mail template bodies only when they still match the original default; if you customized these templates, update them manually to the new layout
- `@ShopsysFramework/Mail/Order/transportInfo.html.twig` and `paymentInfo.html.twig` no longer render the transport and payment heading and image, they are now summary rows; in your customized order mail templates, place `{transport_info}`, `{transport_instructions}`, `{payment_info}` and `{payment_instructions}` below `{products}`
- see #project-base-diff to update your project
