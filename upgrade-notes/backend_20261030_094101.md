#### Complaints and order items in Frontend API now limit the page size ([#4987](https://github.com/shopsys/shopsys/pull/4987))

- `complaints`, `orderItems` and `orderItemsSearch` queries now return the `max-allowed-limit` error when `first` or `last` is over 100, the same as other connection queries; if your Frontend API client requests more items per page, request them in several pages
