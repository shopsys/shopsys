#### Add a complete filter popup and configurable category sidebar ([#4995](https://github.com/shopsys/shopsys/pull/4995))

- categories have a new setting `Number of filter parameters displayed in the sidebar` (`Category::$visibleFilterParametersCount`); the storefront sidebar shows only this number of parameters in the category order, and all filters remain available in the All filters popup
- the migration `Version20261026090302` sets the value to `5` (`Category::DEFAULT_VISIBLE_FILTER_PARAMETERS_COUNT`) for all existing categories, and new categories use the same default value from `CategoryData`
    - if another default suits your project better, skip the migration and add your own one with the preferred value, or update the value of the categories after the migration
    - check the `Filter parameters` section of your existing categories in the administration and adjust the number of parameters and the parameters order, so the most important parameters are displayed in the sidebar
- see #project-base-diff to update your project
