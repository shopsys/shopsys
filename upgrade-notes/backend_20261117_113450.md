#### Paginate product lists on the server and sync them across windows ([#5042](https://github.com/shopsys/shopsys/pull/5042))

- the Frontend API type `ProductList` was changed (wishlist and product comparison):
    - the field `products` now returns the paginated `ProductConnection!` instead of `[Product!]!`, so update your queries to `products(first: N) { edges { node { ... } } }`; without `first` only the first 10 products are returned (also in the responses of the mutations `AddProductToList`, `RemoveProductFromList` and `MoveProductInList`), and at most 100 products can be requested at once
    - the field `itemsCount` was removed, use `products(first: 0) { totalCount }` when you need just the number of products in the list, no product is loaded then
    - to find out whether a product is in the list, use the new field `productUuids` (UUIDs of all products in the list, including products that are not visible on the current domain) instead of searching for the product in `products`, which now returns only the requested page
- `Shopsys\FrontendApiBundle\Model\Resolver\Products\ProductsQuery::productsByProductListQuery()` now accepts `Overblog\GraphQLBundle\Definition\Argument` as its second parameter and returns a connection, and `productsCountByProductListQuery()` was removed, update your extensions of the class
- see #project-base-diff to update your project
