#### Administration JS translations are available before Stimulus controllers connect ([#4889](https://github.com/shopsys/shopsys/pull/4889))

- `project-base/app/assets/js/loadTranslations.js` adds the catalogue to `bazinga-translator` right when the administration bundle is evaluated instead of in a `Register` callback run from `$(document).ready`, so `Translator.trans()` returns translated messages also in `connect()` of Stimulus controllers
- see #project-base-diff to update your project
