#### Add Zbozi.cz category to GTM page metadata ([#4600](https://github.com/shopsys/shopsys/pull/4600))

- Category administration now supports assigning a Zbozi.cz category per locale. Run database migrations to create the new `zbozi_category` and `zbozi_category_categories` tables.
- The Zbozi.cz category list is synchronized from `https://www.zbozi.cz/static/categories.csv` by the new cron module `Shopsys\ProductFeed\ZboziBundle\Model\ZboziCategory\ZboziCategoryCronModule`.
- The GraphQL `Category` type now exposes `zboziCategory`, which returns the assigned Zbozi.cz category text for the current locale.
- see #project-base-diff to update your project
