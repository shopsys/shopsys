#### Prevent complaints from exceeding the purchased quantity ([#4959](https://github.com/shopsys/shopsys/pull/4959))

- if you have overridden `Shopsys\FrontendApiBundle\Model\Complaint\ComplaintApiFacade::create()`, update it accordingly — the remaining quantities are now validated via `validateComplaintQuantities()`
- method `Shopsys\FrontendApiBundle\Model\Complaint\ComplaintApiFacade::validateComplaintItem()` no longer accepts the `$complaintItemInputData` parameter and no longer validates the quantity, the quantity is validated by `Shopsys\FrontendApiBundle\Model\Complaint\ComplaintApiFacade::validateComplaintQuantities()` instead
- after running the migrations, review your complaint statuses in administration and mark every custom status that represents a finished complaint as closed, the migration marks only the default `resolved` status; for complaints already in those statuses, fill in their actual resolution, because only closed complaints with an actual resolution other than money return release the claimed quantity
- see #project-base-diff to update your project
