#### Order items in Frontend API no longer include items of deleted orders ([#4947](https://github.com/shopsys/shopsys/pull/4947))

- `OrderItemApiFacade::createCustomerUserOrderItemsLimitedListQueryBuilder()` and `OrderItemApiFacade::createCustomerOrderItemsLimitedListQueryBuilder()` now exclude deleted orders, so `orderItems` and `orderItemsSearch` queries no longer return items of deleted orders
- see #project-base-diff to update your project
