#### Plural translations use standard plural forms instead of intervals ([#5069](https://github.com/shopsys/shopsys/pull/5069))

- the following translation message IDs were changed; if you translate them in your project (e.g. in another locale) or use them in your code, update them accordingly:
    - `{1}<strong>%count%</strong> promo code has been created|[2,Inf]<strong>%count%</strong> promo codes have been created` → `<strong>%count%</strong> promo code has been created|<strong>%count%</strong> promo codes have been created`
    - `{1} There is one parameter slider that does not have its numeric values filled in.|[2,Inf] There are %count% parameter sliders that does not have its numeric values filled in.` → `There is one parameter slider that does not have its numeric values filled in.|There are %count% parameter sliders that do not have their numeric values filled in.`
    - `{1} You must wait 1 second before submitting the form. |[2,Inf] You must wait %seconds% seconds before submitting the form.` → `You must wait 1 second before submitting the form.|You must wait %count% seconds before submitting the form.` (the `%seconds%` parameter is no longer passed, use `%count%`)
    - `{1} Imported <strong>%count%</strong> holiday.|[2,Inf] Imported <strong>%count%</strong> holidays.` → `Imported <strong>%count%</strong> holiday.|Imported <strong>%count%</strong> holidays.`
