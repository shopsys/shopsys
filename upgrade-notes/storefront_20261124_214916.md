#### Upgrade storefront TypeScript to version 7 ([#5071](https://github.com/shopsys/shopsys/pull/5071))

- TypeScript 7 no longer provides the JavaScript compiler API, so if your storefront has its own tooling that imports the `typescript` package (e.g. linters, ts-node or custom scripts), check that it supports TypeScript 7, otherwise give it its own TypeScript 6 dependency
- see #project-base-diff to update your project
