#### Capture review application emails in Mailpit ([#5063](https://github.com/shopsys/shopsys/pull/5063))

- the local `smtp-server` service now runs Mailpit instead of MailDev; after applying the project changes, update the `smtp-server` service in your local `docker-compose.yml` from the `.dist` file and run `docker compose up -d --force-recreate smtp-server`, the inbox is now at `http://127.0.0.1:8025`
- if you relay local emails to real recipients, replace the `MAILDEV_OUTGOING_*` variables with `MP_SMTP_RELAY_*` ones and export the password as `MP_SMTP_RELAY_PASSWORD`, see [the FAQ](https://docs.shopsys.com/en/latest/introduction/faq-and-common-issues/#how-do-i-deliver-emails-to-real-recipients-from-my-local-environment)
- see #project-base-diff to update your project
