#### upgraded to Symfony 8.1 ([#XXXX](https://github.com/shopsys/shopsys/pull/XXXX))

- Symfony was upgraded from 7.4 to 8.1, update your project accordingly:
    - update all `symfony/*` constraints and `extra.symfony.require` in your `composer.json` from `^7.4` to `^8.1` (see #project-base-diff)
    - copy the new `repositories` section from `composer.json` — it overrides composer metadata (same code, Symfony 8 allowed in constraints) for packages without upstream Symfony 8 support yet:
        - `becklyn/ordered-form-bundle`
        - `enlightn/security-checker`
        - `jms/translation-bundle`
        - `overblog/dataloader-bundle`
        - `overblog/graphiql-bundle`
        - `prezent/doctrine-translatable`
        - `prezent/doctrine-translatable-bundle`
    - copy the new composer patches from the `patch/` directory and their registration in `extra.patches` (see #project-base-diff):
        - `jms-translation-symfony8-php-config.patch`, `overblog-graphiql-symfony8-php-config.patch` and `prezent-translatable-symfony8-php-config.patch` convert XML service definitions to PHP config files, because Symfony 8 removed support for the XML configuration format
        - `enlightn-security-checker-symfony8.patch` fixes the `security-checker` binary for Symfony Console 8
    - upgrade `scheb/2fa-bundle`, `scheb/2fa-email` and `scheb/2fa-google-authenticator` from `^7.6.0` to `^8.6.0`
    - follow the official upgrade guides for your project code: [UPGRADE-8.0](https://github.com/symfony/symfony/blob/8.1/UPGRADE-8.0.md) and [UPGRADE-8.1](https://github.com/symfony/symfony/blob/8.1/UPGRADE-8.1.md), the changes needed in a typical project are:
        - remove empty `eraseCredentials()` methods from your `Symfony\Component\Security\Core\User\UserInterface` implementations, the method was removed from the interface
        - replace `#[TaggedLocator]` and `#[TaggedIterator]` attributes with `#[AutowireLocator]` and `#[AutowireIterator]`
        - add the `void` return type to your `Bundle::build()` overrides
        - remove the `annotations` option from `framework.yaml`, it does not exist anymore
        - convert your own XML service definitions and XML routes to YAML or PHP, the XML configuration format is no longer supported
        - instantiate validator constraints with named arguments instead of an options array, e.g. `new Constraints\Length(max: 255)` instead of `new Constraints\Length(['max' => 255])`
        - remove the `#[Override]` attribute from `App\Kernel::configureContainer()`, the method is now declared as private in a kernel trait, so PHP no longer considers it an override (see #project-base-diff)
        - `Symfony\Bundle\FrameworkBundle\Routing\Router`, `Symfony\Component\HttpFoundation\InputBag` and other Symfony classes are now `final` and cannot be doubled in tests, use real instances instead
- `Shopsys\CodingStandards\Sniffs\General\RequireOverrideAttributeSniff` no longer requires the `#[Override]` attribute on methods whose parent method is private, PHP rejects the attribute in such case
- run `php phing standards-fix` after the upgrade, the upgraded coding standards tooling applies a few new automatic fixes (e.g. `??=` null coalescing assignment)
