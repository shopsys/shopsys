#### admin assets are now built by Rsbuild with Symfony Reprise instead of Webpack Encore ([#{pullRequestId}](https://github.com/shopsys/shopsys/pull/{pullRequestId}))

- the administration layout now renders assets with the `reprise_entry_*` Twig functions, so the application must have `symfony/reprise` installed and the admin assets built by a Reprise-enabled bundler — run `composer remove symfony/webpack-encore-bundle && composer require symfony/reprise` and `npm install` after updating your `package.json`
- if you customized `webpack.config.js`, port your customizations to `rsbuild.config.ts` — entries, aliases, and static copies have direct equivalents, webpack loaders and plugins do not carry over
- JavaScript relying on Encore's `autoProvidejQuery()` must import jQuery explicitly (`import $ from 'jquery';`) — the implicit global injection is gone, only `window.$`/`window.jQuery` set by `registerJquery` remain for third-party plugins
- SVG imports that relied on the webpack `asset/source` rule must use the `?raw` query (`import Icon from 'icons/tabler/check.svg?raw';`)
- `@symfony/stimulus-bridge` was replaced by Reprise's Stimulus integration — `assets/stimulus_bootstrap.js` now calls `startStimulusApp()` from `@symfony/reprise/stimulus`, and controllers previously registered via `require.context()` with the `lazy-controller-loader` are registered with `import.meta.webpackContext()` and load eagerly
- the LiveReload-based `npm run watch` workflow is replaced by hot module replacement — run `npm run dev-server` to get automatic updates in the browser; the dev server reuses port 35729 that docker-compose already exposes, so no compose file changes are needed
- the development CSP appendices in `SecurityHeadersResponseListener` now allow the Rsbuild dev server (`style-src` and `connect-src` for `localhost:35729`) — mirror this if you override the listener
- the unused `select2`, `jquery-hoverintent`, and `jquery.cookie` npm packages were removed — if your own code uses them, add them to your `package.json`
- see #project-base-diff to update your project
