#### Paginate product lists on the server and sync them across windows ([#5042](https://github.com/shopsys/shopsys/pull/5042))

- if you have your own GraphQL queries or fragments reading the Frontend API type `ProductList`, update them:
    - `products` is now a paginated connection, so use `products(first: N) { edges { node { ... } } }` instead of `products { ... }`, and keep `first` small when you request a heavy product fragment, otherwise the query exceeds the Frontend API complexity limit
    - `itemsCount` was removed, use `products(first: 0) { totalCount }` when you need just the number of products in the list, no product is loaded then
    - use `productUuids` to find out whether a product is in the list instead of loading the whole list
- see #project-base-diff to update your project
