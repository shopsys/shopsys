#### Security issues: stored XSS, auth/session weaknesses, unauthenticated endpoints, enumeration oracles ([#XXXX](https://github.com/shopsys/shopsys/pull/XXXX))

- the `accessToken-<domainId>` cookie is now `HttpOnly`, so the browser cannot read the access token any more
    - replace your browser code reading or decoding the access token (e.g. `jwtDecode` to detect an administrator logged in as a customer) with the `isAdministratorLoggedAsCustomer` field of `currentCustomerUser`
    - use `hasRefreshTokenInCookies(domainConfig)` to detect a session in the browser
- the browser is now authenticated only by `POST` requests to the Frontend API sent from the domain origin with the `X-Domain-Id` header
    - if your `PUBLIC_GRAPHQL_ENDPOINT_HOSTNAME_*` points to a different origin than the domain URL, or your browser code sends GraphQL requests via `GET` or without the `X-Domain-Id` header, change it accordingly, otherwise the customer is treated as logged out
- see #project-base-diff to update your project
