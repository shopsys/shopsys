#### Fixed domain icons not being served and shown when the content is stored in a remote storage

- nginx location of administration no longer matches `/content/admin/images/domain/<id>.png`, so the icon is served from the content storage instead of ending with 404 in the application
- `Shopsys\AdministrationBundle\Twig\Runtime\DomainIconRuntime` now lists the icons through the main filesystem instead of the local disk
    - the constructor argument `$kernelProjectDir` was removed and `FilesystemOperator $filesystem` and `string $domainImagesDirectory` were added
    - if you extend the class, update the `parent::__construct()` call and your service definition accordingly
- see #project-base-diff to update your project
