#### Upgrade storefront to Next.js 16 ([#5045](https://github.com/shopsys/shopsys/pull/5045))

- the storefront keeps bundling with webpack, because Next.js 16 uses Turbopack by default; if you run `next build` or `next dev` outside the `package.json` scripts (e.g. in your own Dockerfile or CI), add the `--webpack` flag
- check your own storefront code against the [Next.js 16 upgrade guide](https://nextjs.org/docs/app/guides/upgrading/version-16), e.g. `publicRuntimeConfig`, `serverRuntimeConfig` and `next lint` were removed and the proxy (formerly middleware) runs on the Node.js runtime
- see #project-base-diff to update your project
