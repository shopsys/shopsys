#### ParameterRepository no longer loads product parameter values for all locales ([#4729](https://github.com/shopsys/shopsys/pull/4729))

- `ParameterRepository::getProductParameterValuesByProductSortedByOrderingPriorityAndNameQueryBuilder()` now filters parameter values by the requested locale (and skips parameters without a translated name) directly in the query
- the subsequent PHP filtering was removed from `ProductCachedAttributesFacade::getProductParameterValues()` — the returned data stays the same, only the filtering moved to SQL
    - if your project overrides either method, apply the same change to keep the behavior consistent
- see #project-base-diff to update your project
